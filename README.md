# SQL AI Assistant

Asistente inteligente desarrollado con Laravel e IA generativa para convertir lenguaje natural en consultas SQL dinámicas a partir de schemas reales de bases de datos.

---

# Características

- Generación automática de consultas SQL mediante IA
- Compatibilidad con:
  - MySQL
  - PostgreSQL
  - SQL Server
- Carga manual de schemas
- Importación de archivos `.sql`
- Interfaz moderna y responsive
- Copia rápida de consultas SQL
- Arquitectura modular frontend/backend
- Integración con modelos LLM mediante API

---

# Tecnologías utilizadas

## Backend
- Laravel
- PHP
- Laravel HTTP Client

## Frontend
- Blade
- Bootstrap 5
- JavaScript
- CSS personalizado

## Inteligencia Artificial
- Groq API
- Llama 3.3 70B Versatile
